# Tenzies

Inspired by Scrimba's Intro to React Course, tenzies is a fun game that is inspired by the real-life tenzies game.

## Features
- Can roll 10 dice and produce random numbers for each roll.
- Click the selected die to hold it between the roll (is highlighted when clicked)
- Confetti is displayed when all 10 dice match and you can start a new game when you win.
