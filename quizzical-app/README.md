# Quizzical App

Inspired by Scrimba's Intro to React Course, quizzical is an interactive trivia game where user are asked 5 random questions and they need to answer it.

## Features
- Fetches questions from the Open Trivia Database API.
- Styling shows which answers are correct and incorrect.
- Shows the final score and allows the user to retry a new quiz with different questions
